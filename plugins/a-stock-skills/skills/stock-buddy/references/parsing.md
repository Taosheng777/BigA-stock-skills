# hithink 解析约束

## CLI 调用
`source ~/.zshrc && python3 ~/.claude/skills/hithink-market-query/scripts/cli.py --query "<问句>" --limit <N>`
返回 JSON：`datas`(列表) / `code_count`(命中总数) / `has_more`。

## 1. 字段名按标的类型分两套（必须兼容）
- 股票：`股票代码` / `股票简称` / `最新价`
- 基金/ETF：`基金代码` / `基金简称` / `最新收盘价` / `基金扩位简称`（持仓表"黄金ETF易方达"即扩位简称）

## 2. 日期后缀模糊匹配
多数行情/技术字段带后缀 `[20260616]`（如 `ma5[20260616]`、`成交量[20260616]`）。解析按**字段名前缀**匹配，不要写死后缀。区间字段后缀是起止日 `[20250617-20260616]`，识别为"近一年"类。

## 3. 查询必须 code_count=1
用「6位代码 + 简称」问句。若 `code_count>1`，改用纯代码重查（ETF 尤其要用 6 位代码，简称会误匹配）。

## 4. ETF 基本面留缺口
商品/宽基 ETF 无市盈率/净利润，按铁律标注"该类标的无此字段"，不臆造、不硬凑数据源。ETF 改用 单位净值/基金规模/份额/区间涨幅。

## 5. 四维 + 板块 查询模板（可复用）
- 行情：`<代码> <简称> 最新价 涨跌幅 成交量 成交额 换手率 振幅`
- 资金(股)：`<代码> <简称> 主力资金流向 主力净流入 大单净额 超大单净额`
- 资金(ETF)：去掉"超大单"
- 技术：`<代码> <简称> MACD KDJ RSI 5日均线 10日均线 20日均线 60日均线`
- 基本面(股)：`<代码> <简称> 市盈率 市净率 每股收益 净利润 净利润同比增长 营业收入 ROE 股息率`
- 基本面(ETF)：`<代码> <简称> 单位净值 基金规模 近一年涨跌幅`
- 行业板块榜：`同花顺行业板块今日涨跌幅排名 主力资金净流入额 涨家数 跌家数`
- 概念板块榜：`概念板块今日涨跌幅排名前十 主力资金净流入额`
- 期货价(如锂价)：`碳酸锂期货主力合约 最新价 涨跌幅`
- 板块指数 MA/MACD 常取不全 → 改用龙头个股代理趋势结构（个股技术面字段齐）。
