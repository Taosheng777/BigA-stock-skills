# 常规档工作流（单 agent · personal-aware · 不喊买入）

## 流程
1. `source ~/.zshrc`。读 discipline.md（若涉持仓）。
2. 取数：按 parsing.md 模板跑行情→技术→资金→（个股加）基本面。持仓标的额外算"相对成本盈亏"。
3. 按"状态层 + 信号判定 + 危险信号"组织输出。

## 状态层（不预测）
每个标的/板块输出三件事：
1. 趋势状态：上升/下降/震荡（均线排列 + 价格相对 MA5/10/20/60 的位置）。
2. 企稳信号清单：逐条列"成立/未成立"——缩量止跌？站上 MA5/10？站上 MA20？站上 MA60？MACD 翻红/零轴上方？主力净流入？板块共振？次日确认（留待）？**不给"已企稳"的拍脑袋结论。**
3. 位置提示：现价在近期区间（持仓另含成本）中的位置 + 有无主力承接。

## 信号判定（带纪律护栏）
- 进场信号：成立 / 不成立 / 观察 + 置信度（低/中/高）。
- 触发价：站上什么价位逻辑才成立。
- 失效位=止损：跌破什么价位逻辑作废。
- 仓位上限：受计划书最新版硬约束（v2 起：个股 10% / 主题ETF 15% / 单笔计划风险 0.75% 等，以 discipline.md 指向的计划书为准；持仓标的结合当前占比）。
- 措辞守线："信号成立=逻辑触发，执不执行你决定"。**不说"现在买"、不预测点位、不下单。**

## 危险信号
按 discipline.md 的清单，触及即先红字提示，再谈其余。

**个股情报扫描（持仓体检默认跑；单票速查按需）**：

```bash
python3 ~/.claude/skills/stock-buddy/scripts/danger_scan.py <code...> [--date YYYY-MM-DD] [--json out.json]
```

- 五项：解禁（未来90天）/ 公告风险词（60天）/ 融资余额5日急变（±8% 红字）/ 互动易回复率 / 新闻。脚本自带红字判定，输出时红字先行（与纪律触线合并排序）。
- ETF 自动跳过（五项情报不适用于 ETF）；新闻遇东财间歇风控输出"未跑"→ **照实登记，禁止当"无新闻"或推断补数**。
- 结果为 T3 爬取源：引用须标来源+日期；**数字不入台账**，与 hithink（T1/T2）冲突以后者为准。

## 输出
对话内 Markdown 表格/清单，默认不存。结尾加非投顾+数据来源+数据日声明。

## 选股池跟踪（特例：要回写台账）
当用户要"跟踪选股 skill 选出的池子/某批选股次日/定期表现"时：取各标的最新收盘，按状态层组织点评，并**在选股台账 `<你的投资 vault>/09-选股池跟踪/选股策略胜率台账.md`（未配置 vault 则跳过回写，仅对话点评）对应批次的"跟踪检查点"表追加一行**（检查日/T+N/各标的累计收益/批均值/胜率/沪深300同期），同步更新"批次汇总"的最新检查列。台账头部"记账规则"为唯一格式依据。详细逐只点评可另存 `09-选股池跟踪/YYYY-MM-DD …md` 并从检查点行链接。
